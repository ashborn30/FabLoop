# Third-party dependencies

Clone external research code here for local experiments. The code itself is not vendored in this repository.

```bash
git clone https://github.com/yasumat/RobustPhotometricStereo.git third_party/RobustPhotometricStereo
```

`RobustPhotometricStereo` is GPL-licensed research code. FabLoop scripts load it from this local checkout through `--rps-root`.
